---
title: "Roles and permissions"
---

The system separates **operators** from **people who work with the data**. It's like a building: the administrator keeps the building running properly, safely and within budget; the researcher is responsible for what is collected and what it means.

| Task | Contributor | Researcher | Administrator |
|---|:-:|:-:|:-:|
| Run trial scans with a personal key, submit hashtag suggestion forms | ✓ | ✓ | ✓ |
| View the Overview page (aggregate figures) | ✓ | ✓ | ✓ |
| Approve suggestion forms, manage the hashtag catalog and groups | | ✓ | |
| Run AI labeling, verify labels, view AI confidence | | ✓ | |
| View the list of posts with links (fast-growing posts), finalize referrals | | ✓ | |
| User accounts, role assignment | | | ✓ |
| Apify/OpenRouter keys, AI cost ceiling, model, scan tools | | | ✓ |
| Schedule official scans, monitor errors and costs, contributor activity | | | ✓ |

- **One person can hold both roles** of researcher and administrator. The administrator assigns roles on the **User management** page.
- **Administrators do not automatically see post content and links.** To see them, assign yourself the researcher role. This keeps the number of people viewing raw data to a minimum, in the spirit of personal data protection (Decree 13/2023).
- **Contributors do not verify the system's posts.** They are recognized based on the quality of their suggestion forms, not on the number of posts viewed.
