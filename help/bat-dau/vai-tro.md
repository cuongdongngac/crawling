# Vai trò và quyền

Hệ thống tách **người vận hành** khỏi **người làm việc với dữ liệu**. Giống một tòa nhà: quản trị viên giữ cho tòa nhà chạy đúng, an toàn và trong ngân sách; nghiên cứu viên chịu trách nhiệm về những gì được thu thập và ý nghĩa của nó.

| Việc | Cộng tác viên | Nghiên cứu viên | Quản trị viên |
|---|:-:|:-:|:-:|
| Quét thử bằng key cá nhân, gửi phiếu đề xuất hashtag | ✓ | ✓ | ✓ |
| Xem trang Tổng quan (số liệu tổng hợp) | ✓ | ✓ | ✓ |
| Duyệt phiếu đề xuất, quản lý danh mục và nhóm hashtag | | ✓ | |
| Chạy AI gắn nhãn, xác minh nhãn, xem độ tin cậy AI | | ✓ | |
| Xem danh sách bài kèm đường dẫn (bài tăng mạnh), chốt chuyển tuyến | | ✓ | |
| Tài khoản người dùng, cấp vai | | | ✓ |
| Khóa Apify/OpenRouter, trần chi phí AI, model, công cụ quét | | | ✓ |
| Lập lịch quét chính thức, theo dõi lỗi và chi phí, hoạt động cộng tác viên | | | ✓ |

- **Một người có thể giữ cả hai vai** nghiên cứu viên và quản trị viên. Quản trị viên cấp vai ở trang **Quản lý người dùng**.
- **Quản trị viên không tự động xem nội dung và đường dẫn bài.** Muốn xem thì cấp vai nghiên cứu viên cho mình. Cách làm này giữ số người xem dữ liệu thô ở mức tối thiểu, đúng tinh thần bảo vệ dữ liệu cá nhân (Nghị định 13/2023).
- **Cộng tác viên không xác minh bài của hệ thống.** Họ được ghi nhận theo chất lượng phiếu đề xuất, không theo số bài đã xem.
